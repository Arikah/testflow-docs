# Installation

Follow these steps to install the application on your device.

---

## Download

1. Visit the official download page for your operating system.
2. Choose the installer package (`.exe` for Windows or `.dmg` for macOS).
3. Save the installer file to your computer.

---

## Install

1. Run the downloaded installer file.
2. Accept the license agreement.
3. Choose an installation location and click **Install**.
4. Wait for the setup wizard to finish.

---

## Verify Installation

Launch the application from your desktop or Applications folder to confirm the installation was successful.

Proceed to the [Quick Setup](quick-setup.md) guide to configure your workspace.
