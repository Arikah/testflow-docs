# Application Help Center

Welcome to the official application user guide. This documentation covers software installation, initial configuration, and general usage instructions.

---

## System Requirements

* **Operating System:** Windows 10/11 or macOS 12+
* **System Memory (RAM):** 4 GB minimum
* **Available Storage:** 500 MB free disk space

---

## Installation

1. Download the latest installer package for your operating system.
2. Run the downloaded installer file (`.exe` on Windows or `.dmg` on macOS).
3. Follow the on-screen setup wizard to complete the installation.
4. Launch the application from your desktop or Applications folder.

!!! info "Initial Launch"
    An active internet connection is recommended during the first launch to complete initial license verification and asset synchronization.

Proceed to the [Getting Started](getting-started.md) guide to configure your workspace.
