# Getting Started

Learn the basic interface layout and how to complete your first core workflow.

---

## Interface Layout

* **Top Toolbar:** Global actions, file management, data import/export, and general settings.

* **Left Sidebar:** Quick navigation between projects, dashboards, and reports.

* **Main Canvas:** Active workspace displaying the current view and operational controls.

---

## Creating Your First Item

1. Click the **New (+)** button located on the top toolbar.

2. Enter an item name and assign a target category.

3. Set an optional due date or priority level.

4. Click **Save** to confirm.
